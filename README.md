# Skill Quest

Adaptive, game-like learning from kindergarten to college: math, science, English and history, with pets to raise, leagues, quests and a Scholar Bowl practice room.

Play: https://scarletshadow123.github.io/skill-quest/ (an access code is required).

This repository holds the built website only. Pet art: Microsoft Fluent Emoji 3D (MIT), see `pets/LICENSE-fluent-emoji.txt`.
